# Vizag Taxi - Premium Luxury Website

A world-class responsive web application for **Vizag Taxi**, Visakhapatnam's premier luxury cab service and tour operator. Built with React 18, Vite, and Tailwind CSS.

---

## 🌟 Key Features

- **Brand Styling**: Primary Vizag Orange (`#F57C00`) and Dark Green (`#0B6B3A`) derived directly from the official logo.
- **Sticky Glass Navbar**: Smooth glassmorphism transition on scroll, responsive mobile side drawer navigation.
- **Hero & 3-in-1 Booking Card**: Tabbed instant reservation form for *Hourly Rentals*, *Outstation Trips*, and *Airport Transfers*.
- **Curated Tour Packages**: Horizontal touch-swipeable carousels for Araku Valley, Lambasingi, Borra Caves, RK Beach, Yarada Beach, Kailasagiri, Rushikonda, and Simhachalam.
- **Luxury Vehicle Fleet**: Detailed spec cards for Swift Dzire, Maruti Ertiga, Toyota Innova Crysta, Tempo Traveller, Mini Bus, and Luxury Coaches.
- **Specialized Services & Testimonials**: 10 travel services, verified 5-star customer reviews slider, Instagram photo grid, and social channels.
- **Instant WhatsApp & Phone Reservation**: One-click booking dispatch to WhatsApp (`wa.me`) and hotline call integration.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Glassmorphism System
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Outfit* & *Plus Jakarta Sans*)

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/praghnesh/vizagtaxi.git
   cd vizagtaxi
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
